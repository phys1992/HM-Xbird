# tuichuang 原生重构验证清单

> 分支：`native-rewrite`  
> 产物：`build-out/native-rewrite/tuichuang-native-0.1.0-unsigned.hap`

## 1. 构建

```bash
scripts/build-native.sh
```

预期：

- BUILD SUCCESSFUL；
- HAP 约 600KB；
- 输出 `tuichuang-native-0.1.0-unsigned.hap`。

## 2. 登录

| 场景 | 步骤 | 预期 |
|---|---|---|
| 网页登录 | 首次启动 → 使用网页登录 → 登录 X | 保存 Cookie/queryId，进入主页 |
| Cookie 导入 | 粘贴 `auth_token` + `ct0` | 进入主页；若 queryId 缺失应显示错误而非白屏 |
| 退出登录 | 我的 → 退出登录 | 清空资料/帖子/通知/缓存，回到登录页 |

## 3. 主页

- 为你推荐 / 正在关注切换；
- 下滑分页，底部加载提示；
- 下拉刷新；
- 详情页返回后滚动位置保留；
- 点赞、转推、回复、引用按钮有反馈。

## 4. 折叠屏

- 展开：左时间线、右详情；
- 折叠：单栏；
- 折叠态点击推文：详情占满屏幕；
- 返回：详情 → 列表；
- 我的页关闭分栏：展开态仍单栏。

## 5. 悬浮底栏

- 主页 / 搜索 / 发帖 / 通知 / 我的；
- 选中蓝色 + 圆点；
- 展开态点击左/右半屏，底栏移动；
- 发帖打开原生编辑页；
- 通知角标/分页。

## 6. 媒体

- 图片点击全屏、双指缩放、单击复位；
- 视频点击全屏播放、返回关闭；
- 引用推文点击打开被引用详情。

## 7. 已知风险

- queryId 动态发现依赖 X 网页 bundle，可能失效；
- REST 回退接口可能被 X 下线；
- 未签名 HAP 不能直接 `hdc install`；
- 登录仍保留 ArkWeb 入口。
